# Analisis — Walk Score

**URL:** https://www.walkscore.com/
**Tanggal:** 14 Agustus 2026
**Relevansi:** contoh UX "peta + satu skor besar" paling bersih & ditiru sejagat. Bukan domain risiko, tapi pola skor-per-lokasi-nya emas.

---

## Apa itu

Mengukur walkability alamat mana pun, skor 0–100. Plus Transit Score dan
Bike Score. Tertanam di Redfin/real estate. Model: skor gratis jadi standar
de-facto, API berbayar untuk developer.

## Sistem skor

- **0–100, satu angka dominan** dengan deskripsi kualitatif
  (90-an = "Walker's Paradise", belasan = butuh mobil)
- **Beberapa skor terpisah** (Walk/Transit/Bike) — tapi masing-masing tetap
  satu angka bersih
- Metodologi transparan (jarak ke amenity, decay function, kepadatan)
- Update tiap 6 bulan

## Yang SafeHouse curi — pelajaran utama: KESEDERHANAAN

| Pola | Penerapan |
|---|---|
| **Satu skor dominan, besar, berwarna** | S.A.F.E Score harus jadi HERO — satu angka yang langsung dipahami. Sekarang kartu SafeHouse berteriak sama keras; Walk Score mengajarkan satu angka memimpin |
| **Deskripsi kualitatif menyertai angka** | "65 — layak dengan catatan" lebih bermakna dari "65". Terjemahkan angka ke bahasa keputusan |
| **Skor sekunder tetap bersih** | Sub-skor (banjir/likuefaksi/gempa) tetap satu angka masing-masing, tidak berantakan |
| **Metodologi terbuka** | Link "cara skor dihitung" = kepercayaan |
| **Layout responsif vertikal** | Panel skor vertikal bekerja baik di banyak ukuran — relevan untuk mobile |

## Rubrik kontes

- **UI/UX (15%):** hierarki visual — satu hero score, sisanya pendukung.
  Ini perbaikan termurah & terbesar untuk skor UI SafeHouse
- **Problem Solving (20%):** kejelasan = "seberapa baik app menyelesaikan
  masalah" dari sudut user

## Inti

Walk Score membuktikan: **satu skor yang langsung dipahami mengalahkan
dashboard penuh angka.** SafeHouse punya banyak data bagus — masalahnya
hierarki, bukan kekurangan data. Buat S.A.F.E Score memimpin, sisanya
mendukung.
