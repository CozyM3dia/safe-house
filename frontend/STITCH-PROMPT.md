# Stitch Prompt -- S.A.F.E House

## Prompt 1: Main App (Full Dashboard)

```
Design a dark-themed geophysics property risk analysis web app called "S.A.F.E House". Full-viewport light map (Carto Positron style, soft gray tiles) as the background with floating glass panels overlaid.

Color palette: background #0f0b08 (deep warm black), panels are frosted glass (rgba(22,14,8,0.80) + backdrop-blur), accent color #d4956a (warm amber/copper), text #f0e4cc (cream white), muted text #c4a87e (gold). Risk colors: green #10b981 (safe), amber #f59e0b (moderate), red #ef4444 (danger).

TOP BAR (fixed, 56px height, transparent glass blur):
- Left: hamburger icon + app logo icon (32px) + "S.A.F.E House" (bold, "House" in amber) + subtitle "GEOPHYSICS CORE v3.0" (tiny mono text)
- Center: wide search bar with magnifier icon, placeholder "Search location or run command...", Ctrl+K keyboard shortcut badge on right
- Right: language selector "EN" dropdown, segmented toggle [AUDIT | BATTLE] with active state highlighted, status badge with pulsing green dot "Ready"

LEFT FLOATING PANEL (380px wide, full height minus topbar, frosted glass, rounded-2xl, 16px from edges):
Cards stacked vertically with section dividers ("TECHNICAL METRICS", "RISK ANALYSIS", "LOCATION" -- tiny uppercase labels with gradient line):

1. HERO CARD - S.A.F.E Score: Left side has a 120px SVG arc gauge (240-degree arc, amber gradient with glow, tick marks at 0/25/50/75/100). Score "72" centered inside arc with "/100" below. Right side: shield icon + "S.A.F.E SCORE" label, amber badge "MODERATE" with trend icon, and 3 mini horizontal risk bars (Seismic 65, Flood 25, Soil 40) each with tiny colored progress bar.

2. METRICS GRID (2x2): Four glass tiles -- Vs30 "450 m/s" (amber, mountain icon), PGA "0.48g" (yellow, activity icon), Liq. FS "1.85" (green, waves icon), Elevation "96 m" (purple, droplet icon). Each has tiny progress bar at bottom. Monospace numbers.

3. RADAR CHART: 5-axis radar (Flood, Soil, Air, Seismic, Elevation) on dark background, amber fill at 18% opacity with 2px stroke. Dark grid lines, gold axis labels.

4. SEISMIC WAVEFORM: Realistic seismograph trace SVG, green stroke for low-risk, with subtle glow underneath. Sweeping vertical cursor line. Footer shows "Fault: Sesar Tarahan -- 12 km".

5. PGA DISTRIBUTION: Gaussian bell curve area chart, gradient fill (green for low PGA). Custom styled slider below with gradient track (green to red), circular glowing thumb. Labels "0.1g SAFE" to "1.0g CRIT". Badge shows "SAFE" in green.

6. ADDRESS CARD: MapPin icon + "Site Location" header with copy button. Address text. Three coordinate cells (LAT, LON, ELEV) in bordered tiles with tiny icons. Below: fault proximity card with compass icon, fault name "Sesar Tarahan", distance "12km away", severity badge "MOD" in amber.

7. Full-width amber button "View AI Audit Report" with FileText icon and right chevron.

MAP AREA shows:
- Custom amber map marker pin at a location
- Risk zone overlay: concentric dashed circles (200m, 500m) around marker
- 4 floating dark glass info flags at compass positions showing risk values (FLOOD 25 LOW, SEISMIC 65 MED, SOIL 40 MED, AQI 22 LOW) each with mini progress bar
- Dashed connector lines toward fault/volcano with distance labels

BOTTOM-RIGHT: Collapsed chatbot pill (340px) -- sparkle icon + "Ask AI about this property..." input + send button.

Style: ultra-premium, Bloomberg Terminal meets Palantir. Monospace numbers everywhere. Micro labels are 8-10px uppercase with wide letter-spacing. Every card has subtle hover glow. Spring physics feel. Competition-grade polish.
```
